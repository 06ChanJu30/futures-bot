# 선물 자동매매 봇 — 1단계: 백테스트

과거 차트로 매매 전략을 검증하는 프로그램이에요. **실제 주문 기능은 없고, API 키도 필요 없어요.**

## 처음 한 번만: 준비

1. 파이썬 3.10 이상 설치 (https://www.python.org/downloads/ — 설치 화면에서 "Add python.exe to PATH" 체크)
2. 이 폴더에서 명령 프롬프트(cmd)를 열고:

```
pip install -r requirements.txt
```

## 실행 (명령어 두 줄)

```
python fetch_data.py
python run_backtest.py
```

1. `fetch_data.py` — 거래소에서 BTC 무기한 선물 3년치 1시간봉과 펀딩비 내역을 받아 `data/` 폴더에 저장 (몇 분 걸려요. 다시 실행하면 새로 생긴 부분만 이어서 받아요)
2. `run_backtest.py` — 전략 3개를 워크포워드 방식으로 검증하고 `reports/날짜_시간/` 폴더에 결과 저장
   - `report.md` 요약 리포트, `equity.png` 자산 곡선, `trades_*.csv` 거래 내역

데이터 없이 프로그램 동작만 확인하려면 `python run_backtest.py --synthetic` (가짜 시세 사용, 수익률 의미 없음)

## 들어 있는 전략

| 이름 | 방식 | 언제 강한가 |
|---|---|---|
| trend_ema | 단기·장기 이동평균 방향으로 롱/숏 | 한 방향으로 길게 가는 장 |
| donchian_breakout | 최근 N시간 최고가 돌파 시 롱, 최저가 붕괴 시 숏 | 횡보 후 큰 움직임 |
| rsi_reversion | 큰 추세 방향으로만, 과매도/과매수 되돌림 매매 | 박스권 |

모든 전략은 진입할 때 ATR(평균 변동폭) 기준 손절가를 함께 겁니다.

## 검증 방식 (과최적화 방지)

- **워크포워드**: 12개월 데이터로 파라미터를 고르고 → 바로 다음 3개월(처음 보는 데이터)에 적용. 창을 3개월씩 밀면서 반복하고, **검증 구간 성적만 이어 붙여서** 평가해요.
- 리포트의 '전체기간 최적화 시' 열은 정답을 미리 보고 고른 비현실적인 숫자예요. 이것과 실제 검증 성적의 차이가 크면 과최적화 신호예요.
- 신호는 봉이 마감된 뒤 계산하고 **다음 봉 시가**에 체결 → 미래 데이터를 볼 수 없어요.

## 반영하는 비용과 안전장치 (config.yaml에서 조정)

- 수수료 0.05% (진입·청산 각각), 슬리피지 0.02%, 실제 펀딩비 내역 (없으면 8시간마다 0.01% 가정)
- 레버리지 최대 2배, 1회 거래 손실 자본의 1%로 포지션 크기 자동 계산
- 하루 손실 3% → 그날 매매 중지 / 고점 대비 30% 손실 → 봇 완전 정지
- 청산가 계산 포함 (손절 전에 청산가에 닿으면 강제청산 처리)
- 같은 봉에서 손절과 익절이 둘 다 닿으면 손절로 처리 (보수적)

## 설정 바꾸기

`config.yaml`만 수정하면 돼요. 예: 거래소를 바이비트로 → `exchange: bybit`, 이더리움으로 → `symbol: ETH/USDT:USDT`
