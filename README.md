# 선물 자동매매 봇 — 1단계: 백테스트

과거 차트로 매매 전략을 검증하는 프로그램이에요. **실제 주문 기능은 없고, API 키도 필요 없어요.**

## 처음 한 번만: 준비

```
pip install -r requirements.txt
```

## 실행

```
python fetch_data.py        # 과거 시세·펀딩비 다운로드 (설정: 6년치). 다시 실행하면 모자란 부분만 받음
python check_lookahead.py   # (선택) 전략들이 미래 데이터를 엿보지 않는지 검사
python run_backtest.py      # 전략 검증 → reports/날짜_시간/ 에 결과 저장
```

- `report.md` 결론·순위·비용 분석·과최적화 점검, `equity_4h.png`/`equity_1d.png` 자산 곡선
- `details.md` 구간별 선택 설정, `trades_*.csv` 거래 내역
- 일부만 돌리기: `python run_backtest.py --only tsmom_ensemble --tf 1d`
- 동작 확인만: `python run_backtest.py --synthetic` (가짜 시세)

## 들어 있는 전략

| 이름 | 방식 | 근거 |
|---|---|---|
| tsmom_ensemble | 10·30·60일 등 여러 기간 수익률 방향을 평균내서 롱(숏은 전부 하락 동의 시만) | 시계열 모멘텀 연구, WisdomTree 1·3개월 모멘텀 |

| trend_pullback | 장기 상승 추세 속 RSI(2) 눌림목 매수 | 추세+단기 역추세 결합 사례 |
| donchian_breakout | N일 최고가 돌파 (터틀식) | 비교 기준용 |

자세한 조사 내용과 출처는 `RESEARCH.md`에 있어요.

## 검증 방식

- **워크포워드**: 12개월로 설정을 고르고 → 다음 3개월(처음 보는 데이터)에 적용 → 3개월씩 밀며 반복. 검증 구간 성적만 이어 붙여 평가
- **운 아닐 확률(DSR)**: 후보를 여러 개 시험하고 제일 좋은 걸 고르면 운으로도 좋은 숫자가 나와요. 시험한 후보 수만큼 기준을 높여서 계산
- **과최적화 점검**: '정답 보고 고른 성적'과 실제 검증 성적 비교, 구간마다 같은 설정이 뽑히는지 확인
- **미래 참조 검사**: `check_lookahead.py` (데이터를 잘라서 계산해도 과거 신호가 똑같은지 비교)
- **자동 판정**: `config.yaml`의 `verdict` 기준(샤프 0.8, 운 아닐 확률 90%, 낙폭 25%, 거래 20회)을 모두 넘어야 모의매매 후보

## 반영하는 비용과 안전장치 (`config.yaml`에서 조정)

- 수수료 0.05%, 슬리피지 0.02%, 실제 펀딩비 내역
- 포지션 크기: 목표 변동성(기본 연 40%) 방식, 최대 레버리지 2배
- 추적 손절 (ATR 기준), 강제청산 계산
- 하루 손실 5% → 그날 중지 / 고점 대비 30% 손실 → 완전 정지 (전체 기간 기준)
